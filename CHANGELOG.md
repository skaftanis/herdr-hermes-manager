# Changelog

## 0.3.0 — First public preview

- Profile workspaces, standard metadata group separator, cron controls and recent chats.
- Bots grid inside Hermes Manager; no custom Herdr sidebar/client build required.
- Native continuous Bot conversations shared with Hermes Desktop, streaming activity,
  explicit approvals, scrolling and drag-to-copy.
- Reversible zsh/bash setup, dependency checks, isolated installation/removal tests,
  locked WebSocket dependency and GitHub Actions checks.
- Tested with stock Herdr 0.9.3. Hermes backend compatibility depends on the installed build;
  see README before installing.
